# Session Flow

## Overview

1. A session is a entire workout session for a client / user of the day.
2. A session should be planned in advance and scheduled for a specific date and time.
3. When the time has come, the session is started and client will be carrying out the exercises as planned
4. If user is a trainer, they will be recording the client's form and progress during the session.
   1. Trainer will be using the app to record the client's form and progress during the session.
   2. Maybe real time video, maybe video for post processing.

5. If user is a client, they will be carrying out the exercises as planned.
   1. They will be videoing themselves performing the exercises, hands free.
   2. Likely tripod and phone mount will be used to video the exercises.
